## 粗犷DIY手工感 | 移动端优先

## 🎨 设计理念

### 核心原则
- **真实接地气**: 不追求完美，拥抱手工感的"不完美美学"
- **粗犷但温暖**: DIY朋克精神 + 温暖可亲近的色调
- **日常可穿**: 不是hardcore朋克，而是日常生活中的个性表达
- **独立精品店**: 策展感、每个产品都有故事

### 目标受众
- **年龄**: 25-45岁女性
- **风格**: 日常穿着朋克风格
- **购物习惯**: 主要通过手机购物
- **价值观**: 追求真实自我表达，不随波逐流

## ✍️ 字体系统

### 字体家族

#### 1. Caveat（手写体）
```
用途:
- 产品标题
- 便签内容
- 个性化标注
- 引用语

特点:
- 手写感强
- 亲切温暖
- 不规则但易读

大小建议:
- 标题: 24-32px
- 正文: 18-20px
```

#### 2. Permanent Marker（展示字体）
```
用途:
- Hero大标题
- Logo主标题
- 印章/标签文字
- 强调性按钮

特点:
- 粗犷有力
- 高识别度
- 朋克感

大小建议:
- 大标题: 40-64px
- Logo: 28-36px
- 按钮: 14-16px
```

#### 3. Work Sans（正文字体）
```
用途:
- 产品描述
- 正文内容
- 表单输入
- 导航菜单

特点:
- 清晰易读
- 现代无衬线
- 多字重选择

大小建议:
- 正文: 16px（移动端最小）
- 小字: 14px
- 大段落: 18px
```

### 字体配对原则

```
标题层级:
H1 - Permanent Marker, 40-64px, 复古粉
H2 - Caveat, 32-40px, 温暖黑
H3 - Caveat, 24-28px, 温暖黑

正文层级:
大段落 - Work Sans, 18px, 温暖黑
普通段落 - Work Sans, 16px, 温暖黑
辅助文字 - Work Sans, 14px, 温暖灰
```

## 🎭 视觉元素语言

### 1. 不规则圆角
```css
/* 手绘感圆角 - 每个角都不同 */
border-radius: 50px 40px 45px 35px / 35px 45px 40px 50px;

/* 适用于: 按钮、标签、卡片 */
```

### 2. 轻微倾斜
```css
/* 随机旋转角度 */
transform: rotate(-2deg);  /* 向左倾斜 */
transform: rotate(1deg);   /* 向右倾斜 */

/* 适用于: 产品卡片、照片、便签 */
```

### 3. 手绘边框
```css
/* 多层阴影模拟手绘描边 */
box-shadow:
  3px 3px 0 var(--color-warm-black),
  6px 6px 0 rgba(0,0,0,0.1);

/* 适用于: 按钮、重要元素 */
```

### 4. 纸质纹理
```css
/* SVG噪点纹理 */
background-image: url("data:image/svg+xml,...noise...");
background-blend-mode: multiply;

/* 适用于: 页面背景、卡片背景 */
```

### 5. 拍立得白边
```css
/* 白色边框 + 底部加厚 */
padding: 12px;
padding-bottom: 40px;
background: white;
box-shadow: 0 2px 8px rgba(0,0,0,0.1);

/* 适用于: 产品图片 */
```

```

- 单列为主
```

## 🎬 动画效果

### 微交互

```css
/* 悬停抬起 */
.btn:hover {
  transform: rotate(0deg) translateY(-2px);
  transition: all 0.2s ease;
}

/* 涂鸦漂浮 */
@keyframes doodle-float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-5px); }
}

/* 价格脉冲 */
@keyframes price-pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
```

### 动画原则
- ✅ 微妙、不喧宾夺主
- ✅ 时长: 0.2-0.3秒
- ✅ 缓动: ease, ease-in-out
- ❌ 避免: 闪烁、旋转过快
- ❌ 移动端: 减少复杂动画
